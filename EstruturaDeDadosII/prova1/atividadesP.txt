Lista de Exercícios: Estrutura de Dados e Ordenação
Esta lista de exercícios tem como objetivo consolidar os conhecimentos teóricos e práticos acerca dos algoritmos de ordenação e da análise de complexidade assintótica. A lista é composta por questões divididas por tópicos específicos, complementadas com blocos de questões teóricas e práticas consolidadas. Responda às questões teóricas justificando formalmente e elabore as resoluções práticas com atenção à manipulação da memória e laços de repetição.

Parte 2: Insertion Sort
Contexto: Considere a implementação do algoritmo de ordenação por inserção abaixo:
void
insertionsort (int n, int v[])
{
   for (int j = 1; j < n; ++j) {
      int x = v[j];
      int i;
      for (i = j-1; i >= 0 && v[i] > x; --i)
         v[i+1] = v[i];
      v[i+1] = x;
   }
}
    3. Exercício 3: Analise o código acima e responda às questões:
a) O que acontece se alterarmos o laço for (int j = 1; ... para for (int j = 0; ...?
b) O que acontece se alterarmos a atribuição v[i+1] = x para v[i] = x?

Parte 4: Merge Sort e Análise
    7. Exercício 7: Escreva uma função que receba vetores disjuntos x[0..m-1] e y[0..n-1], ambos em ordem crescente, e produza um vetor z[0..m+n-1] que contenha o resultado da intercalação dos dois vetores dados. Escreva duas versões da função: uma iterativa e uma recursiva.
    8. Exercício 8: Considere a seguinte implementação da função de intercalação do mergesort:
static void
intercala (int p, int q, int r, int v[])
{
   int *w;  // 1
   w = malloc ((r-p) * sizeof (int));  // 2
   int i = p, j = q;  // 3
   int k = 0;  // 4
   while (i < q && j < r) {  // 5
      if (v[i] <= v[j])  w[k++] = v[i++];  // 6
      else  w[k++] = v[j++];  // 7
   }  // 8
   while (i < q)  w[k++] = v[i++];  // 9
   while (j < r)  w[k++] = v[j++];  // 10
   for (i = p; i < r; ++i)  v[i] = w[i-p];  // 11
   free (w);  // 12
}
Um algoritmo de intercalação é estável se não altera a posição relativa de elementos iguais. A função intercala discutida acima é estável? E se a comparação v[i] <= v[j] for trocada por v[i] < v[j]?
    9. Exercício 9: Prove que a função de custo/complexidade C(n) para o merge sort em termos de atribuições de array tem a propriedade O(n log n). Você pode iniciar sua prova com a premissa de que C(1) = 0 e para todos os outros casos C(n) = 2(C(n/2)) + n.

Parte 7: Exercícios Práticos Complementares
    22. Teste de Mesa no Insertion Sort
Enunciado: Considere o arranjo inicial A = [31, 41, 59, 26, 41, 58]. Ilustre passo a passo a operação do Insertion Sort, mostrando os deslocamentos ocorridos toda vez que a variável chave for inserida e o respectivo aumento do subarranjo ordenado.
    23. Implementação do Bubble Sort Otimizado
Enunciado: O Bubble Sort clássico executa passagens desnecessárias se o vetor já estiver ordenado. Escreva o código em linguagem C para o algoritmo de ordenação Bolha declarando uma variável `ntrocas`. Utilize um laço do-while com uma condição condicional dependente de ntrocas e dos limites de iteração.
    24. Contabilização de Operações no Selection Sort
Enunciado: O Selection Sort minimiza trocas às custas de comparações. Baseando-se no vetor V = [209, 330, 25, 15, 42, 2, 32, 8, 55, 145], trace as iterações e comprove aritmeticamente e logicamente que o algoritmo necessitará exatamente de NC = 45 comparações e executará NT = 7 trocas físicas na memória para este cenário.
    25. O Procedimento Merge passo a passo
Enunciado: Considere o momento em que o procedimento Merge precisa fundir as duas subsequências ordenadas: L = [2, 4, 5, 7] e R = [1, 2, 3, 6]. Simule a execução do laço de intercalação que compara as matrizes atestando qual elemento é copiado de volta para o agregado principal em cada ciclo.
    26. Modificação de Ordem no Insertion Sort
Enunciado: Os algoritmos de ordenação baseados em comparação podem ser invertidos com facilidade. Reescreva o laço while central do Insertion Sort (em pseudocódigo) para realizar a ordenação em ordem reversa (não crescente), indicando explicitamente o operador lógico modificado em relação ao limite do elemento avaliado.
    27. Ponto de Intersecção de Complexidade
Enunciado: Suponha que estamos comparando implementações em uma máquina abstrata onde a ordenação por inserção requer 8n² passos e a ordenação por intercalação requer 64n log&sub2; n passos.     28. Otimização em Elementos Iguais
Enunciado: Quando um vetor apresenta múltiplos elementos duplicados (idênticos), algoritmos padrões sofrem com execuções desbalanceadas. Modifique o pseudocódigo do Particionamento para, em vez de gerar um pivô singular, aglomerar todos os termos iguais ao pivô no meio do conjunto delimitado pelos limites de contadores Q e T.
    29. Escolha Estrutural de Algoritmo
Enunciado: Sabendo que o algoritmo Seleção (Selection Sort) é mais recomendado se a função de comparação for simples e os elementos a serem trocados formarem estruturas pesadas visando minorar o excesso de permutas. Escreva a definição de uma struct contendo campos pesados em linguagem C, e providencie a implementação de uma função de swap que intercambie somente os ponteiros de memória em vez da cópia inteira do bloco de dados, validando seu uso com o Selection Sort.
